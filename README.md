# NINJA

A large-scale 3D mobile action game foundation built from scratch.

## Direction
Third-person ninja action with:
- responsive movement and combat
- stamina, health and progression
- enemy AI foundation
- procedural environment foundation
- mobile-ready input layer
- scalable save/progression architecture
- Android build pipeline

## Development rule
This repository is the source of truth. Systems are built as production-ready modules rather than disposable mock screens.

## Engine
Godot 4.x, configured for mobile-friendly Compatibility rendering.
